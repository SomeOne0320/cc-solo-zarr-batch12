Implemented whole-group copy via `zarr.copy`, `zarr.copy_all` and `zarr.copy_store`
(and their asynchronous counterparts under `zarr.api.asynchronous`). These copy a source
group's sub-groups, arrays, attributes and written chunk data into an existing destination
group while preserving the Zarr format, storage layout, sparsity and fill values. The
functions support `if_exists="raise"` (the default, which aborts before writing anything on
a name conflict) and `if_exists="skip"`, plus a `dry_run` mode, and return
`(n_copied, n_skipped, n_bytes_copied)` statistics. Only in-memory and local directory
stores of the same type and Zarr format are supported.
